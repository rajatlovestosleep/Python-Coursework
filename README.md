# Python Coursework

A collection of Python coursework completed as part of my undergraduate studies at Shaheed Sukhdev College of Business Studies, University of Delhi.

The coursework covers fundamental Python programming, NumPy, Pandas, data manipulation, and introductory data cleaning and analysis.

## Topics Covered

- Python Fundamentals
- Problem Solving
- Strings & Lists
- NumPy Arrays
- Pandas Series
- Pandas DataFrames
- Data Manipulation
- Data Cleaning
- Exploratory Data Analysis

## Coursework

### Basic Python
Foundational Python exercises covering programming fundamentals, strings, lists, indexing, and logical problem-solving.

### NumPy
Exercises focused on NumPy arrays and numerical operations.

### Pandas
Exercises covering Pandas Series, DataFrames, data manipulation, and analysis.

### Data Cleaning
Practical work involving data cleaning and preparation using Python and Pandas.

## Tools & Libraries

Python · NumPy · Pandas · Jupyter Notebook
